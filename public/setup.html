📱 Step 3: Install di Safari

⚠️ PENTING: Metode ini menggunakan Bookmarklet — kamu perlu tap bookmark setiap buka Google Dice. Tapi ini 100% work di iOS Safari!

Cara Install:

1
Di Safari, buka halaman apa saja → tap tombol Share (ikon kotak dengan panah ke atas)
2
Pilih "Add Bookmark" / "Tambah Penanda"
Beri nama: 🎲 Dice
Simpan di Favorites
3
Buka Bookmarks (ikon buku) → cari 🎲 Dice → tap Edit
4
Hapus semua isi field URL/Address → Paste kode bookmarklet yang sudah di-copy tadi → Done

Cara Pakai (setiap kali main dadu):

1
Buka Google → search roll dice atau lempar dadu
2
Tap address bar → ketik dice → tap bookmark 🎲 Dice dari suggestions
3
Lihat titik hijau 🟢 di pojok kanan bawah = BERHASIL!
🔴 Merah = gagal koneksi ke server
🟡 Kuning = sedang mencoba koneksi
4
Sekarang atur dadu dari Dashboard, lalu tap Lempar/Roll di Google!

🔧 Alternatif: Manual Paste (Tanpa Install)

Jika tidak mau install bookmark, kamu bisa paste langsung setiap kali:

1
Buka Google Dice di Safari
2
Tap address bar → paste kode bookmarklet → Enter
⚠️ Safari MENGHAPUS javascript: saat paste! Kamu harus ketik manual javascript: di depan kode yang di-paste.
