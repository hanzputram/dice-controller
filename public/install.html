🎲 Dice Controller

Install otomatis di iPhone — tanpa bookmark

Langkah 1 — Install App
1
Download Userscripts dari App Store (gratis)
📥 Buka App Store
2
Buka Settings → Safari → Extensions → Userscripts
Aktifkan dan pilih "All Websites"
3
Buka app Userscripts → tap "Set Userscripts Directory"
Pilih folder mana saja (misal buat folder Userscripts di iCloud)
Langkah 2 — Install Script
💡 Ada 2 cara install script: Otomatis (tap link) atau Manual (copy-paste). Coba Otomatis dulu.

Cara A: Install Otomatis

1
Tap link di bawah ini dari Safari di iPhone:
📥 Install Dice Controller v10.0
2
Jika muncul popup dari Userscripts → tap "Install" / "Confirm"

Cara B: Copy-Paste Manual

1
Tap tombol di bawah untuk copy seluruh script
✅ Script berhasil di-copy!
2
Buka app Userscripts → tap "+" → "New JS"
Hapus semua isi → Paste script yang di-copy → Save
3
Atau buka Files → navigasi ke folder Userscripts → buat file baru dice.user.js → paste kodenya
Langkah 3 — Verifikasi
1
Buka Safari → buka google.com → search roll dice
2
Tap ikon puzzle 🧩 (Extensions) di address bar Safari
3
Tap Userscripts → pastikan "Dice Controller" ada di daftar dan aktif (centang hijau)
4
Refresh halaman (swipe ke bawah dari atas halaman)
Sekarang dadu akan mengikuti pengaturan dari Dashboard.
⚠️ Tidak muncul titik? Coba:
1. Pastikan Userscripts extension aktif di Safari Settings
2. Tap ikon puzzle di address bar → tap Userscripts → aktifkan untuk site ini
3. Pastikan script ada di folder yang benar
4. Refresh halaman
Metode iOS Shortcut
💡 iOS Shortcut bisa menjalankan JavaScript di Safari lewat Share Sheet. Kamu perlu tap Share → Run Shortcut setiap kali buka Google Dice, tapi ini 100% reliable dan bypass CSP.
1
Buka app Shortcuts (Pintasan) di iPhone
2
Tap "+" → beri nama "🎲 Dice"
3
Tap "Add Action" → search "Run JavaScript on Web Page" → tap untuk menambahkan
4
Hapus kode default → paste kode di bawah ini:
✅ Code berhasil di-copy!
5
Tap ikon (i) di bawah → aktifkan "Show in Share Sheet"

Cara Pakai:

1
Buka Google → search roll dice
2
Tap Share (ikon kotak ⬆️) → scroll ke bawah → tap "🎲 Dice"
3
Dadu sekarang akan mengikuti pengaturan dari Dashboard!
